# MusicBridge 0.3.0 — Preview

A native Apple Music → Discord Rich Presence app for Mac.

## Download

Choose **MusicBridge-0.3.0-universal.dmg** below. Open it and drag MusicBridge into Applications. The DMG contains the compiled app, not its source code.

## Included

- English interface, permission description, and connection messages.
- Song title, artist, album covers, playback progress, and Apple Music links on Discord.
- Configurable “Listening to” text.
- Native Icon Composer app icon, menu bar access, and launch at login.
- Simplified footer.
- Universal binary for Apple Silicon and Intel; macOS 13 or later.

## Before installing

This preview is signed ad hoc and **not notarized by Apple**. macOS may block it because the developer is not verified. Intel is cross-compiled but has not been tested on Intel hardware. A Discord Application ID is required; setup instructions are in the README.

GitHub's automatically generated “Source code” archives contain only the public documentation. They are not the installer.

SHA-256 checksums are provided in **SHA256SUMS.txt**.
